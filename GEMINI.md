# Instrucciones para Gemini

Antes de trabajar en este repositorio, lee y sigue:

1. [AGENTS.md](AGENTS.md) — reglas del proyecto, equipo y roles.
2. [REGLAS_GIT.md](REGLAS_GIT.md) — reglamento obligatorio de Git, commits, push y Pull Requests.
3. [ARQUITECTURA.md](ARQUITECTURA.md) — servicios, carpetas y entornos.

Resumen: nunca hagas push a `main` ni a `develop`; trabaja en una rama `tipo/area-descripcion`, abre un Pull Request hacia `develop` y nunca apruebes ni fusiones tu propio Pull Request.
