# agronomia/ — conocimiento agronómico como datos

**Responsable:** Persona 4 · **Suplente:** Persona 1

- `cultivos.yaml`: ciclo, demanda de agua, raíz, tolerancia a sequía, mercado.
- `reglas.yaml`: umbrales del semáforo y de aptitud.
- `rotaciones.yaml`: rotación actual + alternativas.
- `tips/`: una guía por cultivo + modo aprendiz.
- `glosario.yaml`

Todo valor no validado por el agrónomo se marca `[SUPUESTO]`.
