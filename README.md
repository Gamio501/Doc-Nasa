# Rotación Inteligente Piura — NASA Space Apps 2026

App móvil Flutter que funciona sin internet y recomienda cultivos y rotaciones en Piura con datos de la NASA, actualizados cada mes.

## Cómo trabajar

- Parte siempre de `develop`: `git switch develop && git pull --rebase`.
- Una rama por tarea (`feat/area-descripcion`) y Pull Request hacia `develop`.
- Nadie hace push directo a `main` ni a `develop` (ver ARQUITECTURA.md §7).
